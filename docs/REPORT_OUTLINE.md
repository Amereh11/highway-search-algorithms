## 2. Motivation

Explain that the project studies and compares BFS, DFS, UCS, and A* using a highway-routing problem.

## 3. Problem Definition

Model the highway network as a weighted graph:

- Node = city
- Edge = road connection
- Edge weight = Google Maps driving distance
- Start node = chosen departure city
- Goal node = chosen destination city

Define:

- `g(n)` as accumulated driving distance.
- `h(n)` as straight-line distance to the target.
- Estimated direct-flight time as `h(n) / 250 mph`.

### A*
Explain:

`f(n) = g(n) + h(n)`

and why straight-line distance is a useful heuristic.
